# Doorika Couture

Luxury fashion storefront.

## Open the store

1. Download `doorika-couture.html` from the Grok chat (Download HTML).
2. Double-click the file to open it in any browser — collection, try-on, link and QR are inside.
3. For a public internet link, tap **Publish** in Grok Build, then scan the QR on the live site.

Owner password: use the owner button on the live Grok app (not in this file).
